# Site Health Monitor Python

Herramienta en Python para comprobar disponibilidad, detectar enlaces rotos y generar reportes de mantenimiento de sitios web.

## Estado

Proyecto en preparación. Las comprobaciones todavía no están implementadas.

## Primera versión prevista

- Leer una lista explícita de páginas públicas.
- Comprobar respuestas HTTP y destinos de redirección.
- Registrar tiempos de respuesta y errores.
- Generar un reporte por consola y en CSV.

Después se evaluarán comprobaciones de enlaces, imágenes y contenido esperado.
